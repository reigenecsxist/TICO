Gabriel de Moura UEG Pires do Rio
Extensão Universitária Vagas Abertas Edital 04/2026

Estufa Semi-Hidropônica Integrada com IoT e Automação Solar

Desenvolvimento e implantação de uma estufa sustentável com madeira tratada de eucalipto, equipada com sensores de umidade, temperatura e condutividade elétrica conectados por microcontroladores ESP32. O projeto busca fornecer tecnologia de baixo custo para horticultores familiares de Goiás.

Coordenador / Líder Prof. Dr. Ricardo Albuquerque
Câmpus UEG CET - Anápolis (Ciências Exatas)
Oportunidades 3 Vagas Disponíveis
Vigência Out/2026 - Out/2027 (12 meses)

Sobre o Projeto & Metodologia

A agricultura de precisão e os cultivos semi-hidropônicos representam um salto de produtividade e economia de água para o cerrado goiano. No entanto, o custo comercial dos sensores e sistemas automáticos de dosagem de nutrientes é inacessível para pequenos produtores.

Este projeto de extensão multidisciplinar une estudantes de Engenharia de Software, Sistemas de Informação e Agronomia para conceber um ecossistema completo: desde a estrutura física e painéis fotovoltaicos até o aplicativo web de telemetria e controle em tempo real.

Competências Aplicadas no Projeto:

Java / Spring Boot Eletrônica Arduino / ESP32 Hidroponia PostgreSQL UI/UX Design
